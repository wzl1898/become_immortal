# 阶段引导

阶段是引导层维护的跨事件目标，当前状态保存在 `director_state.stage`：

```json
{"goal":"获得《引气诀》","event_budget":4}
```

- `goal`：完成后会长期改变主角实力、人际关系、宗门或社会身份、重要资产或处境的目标。
- `event_budget`：包含下一次新事件在内，还允许创建多少个事件来明确完成或失败。

## 生成

没有当前阶段时，`stage_guidance` Agent 根据以下内容动态生成阶段：

- 主角当前实力、功法、装备和状态；
- 已形成的复仇、报恩、承诺与重要人物关系；
- 宗门、势力、身份和社会关系；
- 最近剧情、玩家持续投入方向与事件历史；
- 固定世界事实和历史阶段。

Agent 只输出 `goal` 和 `event_budget`。预算由后端限制在 3～6；无效输出使用当前故事卡和固定奖励构造预算为 4 的兜底阶段。

## 事件约束

每次创建新事件，事件 Agent 都会收到阶段目标及创建前的剩余预算：

- 每个事件必须给目标带来可验证进展；
- 只有新事件成功安装后才扣减预算；普通剧情回合、复用已有事件和异步预生成种子都不扣减；
- 预算为 1 时，事件必须直接结算阶段成功或不可逆失败，不能再增加中间线索；
- 如果结算事件没有实际结算，预算保持为 0，后续事件仍按“最后事件”约束，不会静默生成新阶段。

## 完成与历史

导演审计读取实际正文和状态面板，独立输出 `stage_completed` 或 `stage_failed`。只有正文明确完成目标，或产生明确且不可逆的失败，阶段才会归档到 `director_state.stage_history` 并清空。下一次创建事件前会动态生成新阶段。

旧 `payoff` Agent 已退出正常导演规划路径；历史存档字段和辅助函数暂时保留兼容。
