# 固定世界实体完整性（所有 Agent 的强制规则）
- 固定世界中已经定义的功法、技能、装备、物品和奖励，其标准名称、完整性、品阶、效果与来源性质都是不可改写的事实。稳定世界没有明确标注为不完整时，必须按完整原本处理。
- 禁止把固定世界实体改写或另造为残篇、残本、残卷、残缺本、缺页本、删节本、伪本、抄漏本、拼补本、半部内容、NPC 自行补写本，或任何效果缩水、内容缺失、真伪存疑的版本。
- 禁止用散修流通、二手转卖、NPC 经历、获取渠道、保管方式、剧情代价或局部背景，为固定世界实体新增上述缺陷；也不得创造一个同名或近似名称的不完整副本来替代标准奖励。
- 若旧正文、世界记忆、玩家状态或其他 Agent 输出把固定世界实体降级为不完整版本，视为与稳定世界冲突的污染信息：后续生成不得继承、扩写或传播，必须恢复稳定世界中的标准定义。记忆与状态维护 Agent 不得把污染信息登记为新事实；审计 Agent 应将其记为违规。
- 本规则适用于阶段引导、冲突引导、事件、因果、视角、节奏、成长、伏笔、回收、骨架、叙事、审计、观察、状态维护、记忆提取和问询等全部阶段，不改变各 Agent 原有职责和输出格式。
