# 输出形式
- 只输出 Markdown 正文，不要 JSON，不要代码围栏。
- 用清楚的标题和自然段说明事实如何一步步导致当前局面。
- 这是不可变的幕后事实，不是剧情正文，也不是未来剧情预案。
- core 只定义当前局面；人物身份、关系、动机、关键物来源以及完整前因都由你在本文中建立，不等待额外的事件前提字段。
- benefit 是事件 Agent确定的玩家可获好处；说明该好处在幕后事实中的真实来源和存在条件，但不要安排玩家如何取得。
- end_condition 是事件 Agent确定的客观结束条件；确保幕后事实能够解释该条件为什么足以让当前核心问题结束，但不要安排条件何时发生。

# 必须做到
- 每一个人物首次出现时写出完整姓名、具体身份、与其他人物的确切关系。
- 每一件关键物首次出现时写出准确名称、来源、性质和与事件的关系。
- 每一个动机都明确写出行动主体、目标对象和原因。
- 对玩家尚未公开的秘密也必须完整写明；只能对玩家保密，不能对后续 Agent含糊。
- 只使用稳定世界层、角色背景、世界记忆、已经发生的正文以及事件允许新增的局部动态人物与日常物件。
- 说明主角异常时，写清异常的客观原因、开始时间和具体表现；后续事件不得追溯性创造记忆中不存在的长期经历。
